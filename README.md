# Django Login System Project

A simple Django project that implements user signup, login, admin access, database operations, and CRUD APIs for managing user data.

The main functionalities:

- User signup
- User login
- Login success page
- Django admin setup
- User model and database operations
- CRUD APIs for user data
- API testing using Postman

## CRUD Operations

The following CRUD operations are implemented:

- Create a user
- Get all users
- Get a single user
- Update user details
- Delete a user

## Project Folders

- `LoginSystem/` - Main Django project configuration.
- `Loginify/` - Django application containing models, views, forms, serializers, URLs, and admin configuration.
- `templates/` - Contains the HTML pages used in the project.
- `screenshots/` - Contains screenshots of the completed tasks and Postman testing.
- `requirements.txt` - Contains the Python packages used in the project.
